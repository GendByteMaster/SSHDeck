# SSHDeck v0.1.0_beta

SSHDeck `v0.1.0_beta` is the first public beta of the local-first desktop SSH workspace.

## Highlights

- real OpenSSH-backed PTY terminal sessions;
- local server registry with favorites, groups, OpenSSH import/export and status diagnostics;
- SFTP remote browser with navigation, mkdir, rename, delete, upload/download and staged diagnostics;
- global Transfers queue with progress, speed, ETA, cancel and retry;
- Local (`-L`), Remote (`-R`) and Dynamic/SOCKS (`-D`) port forwarding with shared lifecycle state;
- dedicated Sessions and persisted History workspaces;
- structured Logs with secret/private-key redaction;
- unified Workbench Search;
- versioned Settings with migration/validation;
- shared command routing across Activity Bar, menus, Command Palette, shortcuts and Bottom Panel.

## Verified release gates

- Rust fmt, Clippy and tests;
- UI contract checks;
- frontend production build;
- Tauri backend tests/check;
- Windows PowerShell 5.1 smoke preflight;
- Windows release binary build;
- Windows desktop startup smoke;
- local Windows functional runtime smoke: **10/10 checks passed**.

## Beta limitations

- Windows is the verified runtime target for this beta;
- Linux/macOS packaging is not yet part of the release matrix;
- SFTP directory transfer/delete operations are intentionally non-recursive;
- password-only automated SFTP is not supported because SSHDeck keeps the system OpenSSH batch-mode safety boundary;
- the workspace/settings persistence schema may evolve before a stable `v1.0.0`.

## Artifact

The release includes a portable unsigned Windows x64 executable:

`SSHDeck-v0.1.0_beta-windows-x64.exe`

Windows may show a SmartScreen warning because this beta binary is not code-signed yet.
